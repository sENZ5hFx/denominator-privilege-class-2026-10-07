## Core insight

A published rate, catch, occurrence, or named fraction is granted the privilege of being a count of real events. The denominator is a survey construct, completeness model, effort estimate, or discoverable-set treated as observed. Changing the denominator rewrites the numerator's history without any object in nature moving.

Kill rule: if the pipeline already treats the denominator as a first-class estimand with its own error (not as observed trips / volume / area / "all microbes"), the instance leaves DPC.

## Primary — NMFS FES rewrites 2024 striped bass catch −31.2% with no fish moved

Exact retrieved figures for **2024 striped bass**:

| Object | Original | Revised | Change |
|---|---:|---:|---:|
| Total catch | 20,822,514 | 14,323,640 | **−31.2%** |
| Live releases | 19,093,770 | 13,111,145 | **−31.3%** |
| Summer flounder coastwide | 29,993,105 | 27,929,969 | −6.88% |

Mechanism retrieved: FES private-boat and shore **trips** (the denominator) were overreported in two-month waves. Catch = catch-per-trip × effort. For-hire effort (a different survey) was unaffected. Historical trends in activity remain largely the same; the updated totals are systematically lower with smaller margins of error.

## Co-primary — unbinned-contig discoverable set as the 'all microbes' denom

Nature Microbiology, 2 Apr 2026, DOI 10.1038/s41564-026-02314-6. 92,187 public metagenomes; 502 million marker-gene sequences. Predicted **~705,000 bacterial** and **~27,000 archaeal** species-level clades, the vast majority hidden among unbinned contigs. Estimate: **10 undescribed archaeal and 145 undescribed bacterial phyla** discoverable in this dataset alone. Soils, wetlands, rhizosphere, freshwater, and non-mammalian guts are hotspots. The gap between discovered (genomically represented) and discoverable (unbinned) **is widening**.

GigaScience 2025: 270 Gbp soil still a fraction; models project **>10 Tbp** to approach saturation; >99% of 11,000 biosynthetic gene clusters unmatched; 0.7% of contigs assignable to a cultured species.

**DPC remainder:** the cultured/named fraction treats the discoverable set as a fixed "all microbes" denominator. That denom grows under more sequencing. The named fraction falls without any named species going extinct.

`remainder_as_denom` queues **Remainder-Growth Class (RGC)** — observational effort grows the unnamed remainder faster than the named set. Kill rule would be saturation/rarefaction, which differs, so it is **not minted**. Skill rule 7 leftover.
