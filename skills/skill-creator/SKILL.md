  When a new class is logged, write a SKILL.md that states the kill rule,
  the duals it is not, and the leftover it must not absorb.
---

# skill-creator

A class without a kill rule is a slogan.

Write:

- one-sentence remainder
- kill rule that a later paper can fire
- explicit "do not re-issue" list
- leftover queue if iteration surfaces a different kill rule

Do not mint the leftover in the same session.
